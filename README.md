## 🚀 How to View Locally

Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Brave, Safari):
- **Double click `index.html`**, or
- Right click `index.html` -> **Open with** -> **Google Chrome** (or your preferred browser).
- Or using VS Code / Cursor: Right click `index.html` -> **Open with Live Server**.

## 🌐 How to Host Online for Free (GitHub Pages)

To have your live portfolio URL just like `https://Aradhyay.github.io/portfolio/`:

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and create a new public repository named `portfolio` (or `Aradhyay.github.io`).
2. **Push your files**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Aradhya Dwivedi Portfolio"
   git branch -M main
   git remote add origin https://github.com/Aradhyay/portfolio.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - In your GitHub repo, click **Settings** -> **Pages** (on the left sidebar).
   - Under **Build and deployment** -> **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
   - In 1–2 minutes, your website is live at: `https://Aradhyay.github.io/portfolio/`!
